# Vehicle Analysis Dashboard

## Project Description
This project is a web application developed with Streamlit that allows you to visualize and analyze car sales advertisement data. The dashboard includes interactive charts to explore different aspects of vehicle data.

## Features
- Interactive histograms for distribution analysis
- Scatter plots to identify correlations
- Interactive controls (buttons/checkboxes) for data filtering
- Responsive, simple and intuitive web interface

## How to run locally
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `streamlit run app.py`

## Technologies used
- Python
- Streamlit
- Pandas
- Plotly Express
